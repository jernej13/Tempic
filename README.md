# Tempic
Small solar powered ESP32c6 based indoor/outdoor WiFi/Zigbee sensor node.

# Features
- Onboard ESP32 C6 mini with
    - WiFi 6 (2.4 GHz)
    - Zigbee 3
    - Bluetooth 5.3

- BME688
    - Temperature
    - Humidity
    - Pressure
    - CO2 
    
- BMV080
    - P.M. 1.0
    - P.M. 2.5
    - P.M. 10

- Small 5x5cm solar panel
- Small 5x5cm lipo battery
